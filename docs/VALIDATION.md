## 仍然开放的验证项

- 24/48 小时持续运行和资源趋势；真实低内存压力、系统重启后的恢复。
- Headscale 与多个真实 Tailnet 同时运行；完整 IPv6 端到端覆盖。
- 系统杀进程后的后台自主恢复。当前实现依赖重新打开应用触发恢复。
- 原始 IP 与物理网络重叠时的系统路由行为；应用自带 DoH/DoT 的域名分流边界。
- 不同宿主平台的工具链与 DevEco 全流程；旧源码引导路径对当前依赖的适用性。
- 早期保存配置问题：本任务曾收到 `13900002`、应用目录无效、准备配置目录失败；后来的记录已有多配置与更新成功，但没有针对每个早期报错的独立关闭记录。若用户仍遇到，应在当前版本重新复现，不把历史错误直接标为已修复或全局现存故障。
